Chapter 5External APIs and Services

TheAgriDoctor uses six external data services, Supabase, free map tiles and three browser APIs. Every service that needs a secret key is called only from the server; the key is read from an environment variable and never sent to the browser.

5.2 OpenRouter API (primary AI)

OpenRouter is a single API in front of hundreds of AI models from many companies. TheAgriDoctor uses its free models as the first choice in every AI chain. The request format is the widely used "chat completions" format: a list of messages (system, user, assistant) and options such as max_tokens and temperature.

ItemValue

src/lib/ai.ts — building an OpenRouter request (excerpt)
function openRouterBody(step: ChainStep, req: AiRequest, opts: AiOptions, stream: boolean) {
  const msgs: unknown[] = []
  if (req.system) msgs.push({ role: 'system', content: req.system })
  req.messages.forEach((m, i) => {
    const isLastUser = i === req.messages.length - 1 && m.role === 'user'
    if (isLastUser && req.images?.length) {
      msgs.push({ role: 'user', content: [
        ...req.images.map((url) => ({ type: 'image_url', image_url: { url } })),
        { type: 'text', text: m.content },
      ] })
    } else {
      msgs.push({ role: m.role, content: m.content })
    }
  })
  return {
    model: step.model, messages: msgs,
    max_tokens: opts.maxTokens ?? 1000, temperature: opts.temperature ?? 0.4, stream,
    ...(opts.json ? { response_format: { type: 'json_object' } } : {}),
  }
}

// headers: Authorization: Bearer <OPENROUTER_API_KEY>, HTTP-Referer, X-Title

5.3 Google Gemini API (backup AI)

Google's Gemini API is the independent second provider. It is used automatically when the OpenRouter models fail. Gemini uses its own request format: contents with roles user and model, a systemInstruction, and images as inline_data.

return {
  contents,                                        // user / model turns
  ...(req.system ? { systemInstruction: { parts: [{ text: req.system }] } } : {}),
  generationConfig: {
    maxOutputTokens: opts.maxTokens ?? 1000,

5.5 Agro Monitoring API (satellite field data)

Agro Monitoring (by OpenWeather) works on polygons: the farmer's field boundary is registered once, and every later request asks for data about that exact field.

Endpoint (base: api.agromonitoring.com/agro/1.0)Returns
POST /polygons · DELETE /polygons/{id}Registers or removes the field boundary; returns its id and area in hectares
GET /weather · GET /weather/forecastWeather now and forecast for the field (temperatures in Kelvin)
GET /soilSoil moisture (0–1) and soil temperature at surface and 10 cm
GET /uviUV index
GET /image/searchSatellite scenes (Sentinel-2, Landsat 8) with NDVI, true-colour images and statistics; the app picks the scene with the least cloud
GET /weather/history/accumulated_temperatureGrowing degree days (heat units) over 30 days
GET /weather/history/accumulated_precipitationRainfall over 30 days
src/lib/agro.ts — building a square field around the farm (excerpt)
// Build a square polygon (GeoJSON) of approx `radiusMeters` around a lat/lng.
export function buildSquarePolygon(lat: number, lng: number, radiusMeters = 300) {
  const dLat = radiusMeters / 111_320                                    // metres per degree of latitude
  const dLng = radiusMeters / (111_320 * Math.cos((lat * Math.PI) / 180))
  const coords = [
    [lng - dLng, lat - dLat], [lng + dLng, lat - dLat],
    [lng + dLng, lat + dLat], [lng - dLng, lat + dLat],
    [lng - dLng, lat - dLat],                                            // close the ring
  ]
  return { type: 'Feature', properties: {}, geometry: { type: 'Polygon', coordinates: [coords] } }
}

5.7 RainViewer API

A free, public radar service. The app downloads the list of radar frames (about two hours of past frames plus a short forecast) from GET https://api.rainviewer.com/public/weather-maps.json and plays them on the map one after another, every 650 milliseconds.

export async function uploadDiagnosisImage(image: Blob, userId: string): Promise<string> {
  const supabase = createClient()
  const ext = image.type === 'image/png' ? 'png' : 'jpg'
  const path = `${userId}/${Date.now()}-${Math.random().toString(36).slice(2)}.${ext}`
  const { error } = await supabase.storage.from(DIAGNOSIS_BUCKET).upload(path, image, {
    cacheControl: '3600', upsert: false, contentType: image.type || 'image/jpeg',
  })
  if (error) throw new Error(`Upload failed: ${error.message}`)
  return path          // the PATH is stored; a fresh signed link is created when shown
}
