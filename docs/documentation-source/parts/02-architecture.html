Chapter 4System Architecture

TheAgriDoctor has three tiers: the farmer's browser, the Next.js server hosted on Vercel, and the services behind it (Supabase, AI providers and data providers). The browser never talks to a service that needs a secret key; only the server does.

4.1 High-level architecture

TierResponsibility
BrowserShows pages, maps and charts; captures photos and voice; compresses photos; streams chat answers. Holds only the public Supabase key.
Next.js serverChecks the user's session, validates input, applies rate limits, calls AI and data providers with secret keys, writes to the database.
SupabaseStores all data in PostgreSQL with row-level security, handles login, stores photos privately.
AI providersGenerate diagnoses, advice, task plans and forum answers.
Data providersWeather, satellite field data and market prices.

4.2 How a request flows through the system

Every page visit and every API call passes through the same checks. The middleware refreshes the login session on each request; pages redirect signed-out visitors to the login page; API routes answer 401 Unauthorized instead.

src/lib/supabase/middleware.ts — route protection (excerpt)
const PUBLIC_PATHS = ['/login', '/signup', '/auth', '/favicon.ico']

export async function updateSession(request: NextRequest) {
  // … create a Supabase server client bound to the request cookies …
  const { data: { user } } = await supabase.auth.getUser()

  const pathname = request.nextUrl.pathname
  const isPublic = PUBLIC_PATHS.some((p) => pathname === p || pathname.startsWith(p + '/'))
  const isApi = pathname.startsWith('/api/')

  if (!user && !isPublic && !isApi) {
    const url = request.nextUrl.clone()
    url.pathname = '/login'
    url.searchParams.set('redirect', pathname)   // come back here after login
    return NextResponse.redirect(url)
  }
  return response
}
