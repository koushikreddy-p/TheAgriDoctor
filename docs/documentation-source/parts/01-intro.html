Each feature has a step-by-step walkthrough, a flowchart and a short excerpt of the real source code, so a reader can understand the concept without opening the code.

    1.2 Project overview

    TheAgriDoctor is a web platform for Indian farmers that combines artificial intelligence, satellite data and live government data in one place. A farmer can:

    • photograph a diseased leaf and receive a full diagnosis with organic and chemical treatment, dosage, prevention tips, expected yield loss and the number of days within which to act;
    • chat with an AI farming advisor in their own language, by typing or speaking, and get answers personalised to their own farms, crops and recent diagnoses;
    • register farms, track crop cycles and receive an AI-generated 14-day task plan for each crop;
    • monitor each field by satellite (crop health index NDVI, soil moisture, soil temperature, UV, rainfall, heat units) and receive automatic alerts;
    • check weather, an animated rain radar and live mandi (market) prices;
    • ask questions in a farmer community, with an automatic AI answer;
    • see a map of disease outbreaks reported by all farmers, anonymised.

    Behind every AI feature is a multi-model fallback engine: requests go first to free AI models on OpenRouter and automatically fall back to Google Gemini, so the failure of one provider never stops the farmer.

    1.4 Scope of the system

    The system is a responsive web application (phone and laptop) made of 17 feature modules, 24 server API routes and 10 database tables. It covers diagnosis, advice, planning, monitoring, alerts, market information and community. It does not sell inputs, process payments or control farm equipment.

    UsersFarmers (each sees only their own data)
    PlatformsAny modern browser on phone, tablet or laptop
    Languages10 answer languages; voice in EN, HI, TE
    HostingVercel (application) + Supabase Cloud (data)

    Chapter 2Objectives

    2.1 Primary objectives

    1. Early disease detection — let any farmer identify crop diseases from photos and receive treatment guidance immediately.
    2. Personalised expert advice — provide an always-available AI advisor that answers in the farmer's language using their own farm data.
    3. Smart farm management — keep farms, crop cycles and tasks in one place, with AI-generated task plans for each crop.
    4. Proactive field monitoring — use satellite and weather data to warn the farmer about heat, frost, dry or waterlogged soil, heavy rain and poor crop health.
    5. Market and community access — show live mandi prices and let farmers help each other, with AI support.

    2.2 Technical objectives

    1. High availability of AI — no single AI provider is a point of failure (multi-model fallback chain, Chapter 7).
    2. Data privacy by design — each farmer can read and change only their own data, enforced by the database itself (row-level security, Chapter 9).
    3. Secrets stay on the server — no API key ever reaches the browser (Chapter 10).
    4. Works on rural networks — photos are compressed on the phone, answers stream word by word, pages show loading placeholders instantly.
    5. Verifiable quality — automated tests for the AI pipeline and for database security (Chapter 11).

    3.5 Why these technologies

    • Next.js lets one project hold both the pages and the secure server code, so API keys stay on the server and deployment is one step.
    • Supabase gives a real PostgreSQL database with built-in login, file storage and row-level security, which is how privacy is enforced.
    • OpenRouter gives access to many AI models through one API, including free models; Gemini adds a second, independent provider.
    • Leaflet is a lightweight, free map library that works well on phones.
    • Free tiers everywhere: the whole platform can start at zero cost and scale later.
